What this starter stores

The starter does not create user accounts. Chat history is held in page memory and is not intentionally saved to a database. Browser session storage remembers the age-gate confirmation for the current session.

AI processing

When live AI is enabled, messages you submit are sent through the website's server-side Worker to the configured AI provider to generate a reply. The provider may process and retain request data under its own policies. Do not enter passwords, financial details, health information or other sensitive personal data.

Hosting and logs

The hosting provider may process technical information such as IP addresses and request logs to operate and secure the site. Check the provider's current privacy terms.

Advertising

No advertising network is connected in this starter. If you later add one, update this notice, implement any required consent mechanism, and disclose cookies or similar technologies as required by applicable law.

Contact

Add a working contact email and your business/operator details before launch.
